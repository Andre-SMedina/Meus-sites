Preparação de ISO Customizada do Windows com Sysprep

Guia completo para criação de uma imagem personalizada do Windows utilizando Sysprep, DISM e Windows ADK.

Objetivo

Este procedimento permite personalizar uma instalação do Windows, capturar a imagem utilizando o DISM e gerar uma nova ISO bootável contendo todas as customizações realizadas.

1. Entrar em Modo Auditoria

  1. Inicie a instalação do Windows normalmente.
  2. Após a cópia dos arquivos de instalação para o disco, quando aparecer a tela de seleção de idioma e região, pressione:

    CTRL + SHIFT + F3
  3. O Windows reiniciará automaticamente e entrará no Modo Auditoria (Audit Mode).
Caso precise retornar ao modo auditoria posteriormente: 
C:\Windows\System32\Sysprep\sysprep.exe /audit /reboot

2. Personalizar o Windows

  1. Instale aplicações necessárias.
  2. Configure políticas, atalhos e personalizações desejadas.
  3. Realize atualizações do Windows.
  4. Remova softwares que não farão parte da imagem final.
  5. Crie uma nova partição com aproximadamente 60 GB.
  6. Crie a pasta D:\iso (ou letra equivalente).
  7. Copie todo o conteúdo da ISO original do Windows para essa pasta.
  8. Não copie o arquivo sources\install.wim.

3. Criar o arquivo unattend.xml

Salve o arquivo de resposta automática em:

C:\Windows\System32\Sysprep\unattend.xml

Esse arquivo será utilizado pelo Sysprep para automatizar o processo de generalização.

Conteúdo do arquivo unattend.xml

Crie o arquivo abaixo em: 

C:\Windows\System32\Sysprep\unattend.xml

Este arquivo automatiza a configuração inicial do Windows após a execução do Sysprep, definindo idioma, fuso horário, criação de usuário administrador local e logon automático.

📄 Clique para expandir ou recolher o arquivo unattend.xml 
<?xml version="1.0" encoding="utf-8"?>
<unattend xmlns="urn:schemas-microsoft-com:unattend">

    <settings pass="oobeSystem">

        <component name="Microsoft-Windows-International-Core"
                   processorArchitecture="amd64"
                   publicKeyToken="31bf3856ad364e35"
                   language="neutral"
                   versionScope="nonSxS">

            <InputLocale>pt-BR</InputLocale>
            <SystemLocale>pt-BR</SystemLocale>
            <UILanguage>pt-BR</UILanguage>
            <UserLocale>pt-BR</UserLocale>

        </component>

        <component name="Microsoft-Windows-Shell-Setup"
                   processorArchitecture="amd64"
                   publicKeyToken="31bf3856ad364e35"
                   language="neutral"
                   versionScope="nonSxS">

            <TimeZone>E. South America Standard Time</TimeZone>

            <OOBE>
                <HideEULAPage>true</HideEULAPage>
                <HideOnlineAccountScreens>true</HideOnlineAccountScreens>
                <HideWirelessSetupInOOBE>true</HideWirelessSetupInOOBE>
                <HideLocalAccountScreen>true</HideLocalAccountScreen>
                <ProtectYourPC>3</ProtectYourPC>
            </OOBE>

            <UserAccounts>
                <LocalAccounts>

                    <LocalAccount wcm:action="add"
                        xmlns:wcm="http://schemas.microsoft.com/WMIConfig/2002/State">

                        <Name>Admin</Name>
                        <DisplayName>Admin</DisplayName>
                        <Group>Administrators</Group>

                        <Password>
                            <Value>xenha</Value>
                            <PlainText>true</PlainText>
                        </Password>

                    </LocalAccount>

                </LocalAccounts>
            </UserAccounts>

            <AutoLogon>
                <Enabled>true</Enabled>
                <Username>Admin</Username>
                <LogonCount>1</LogonCount>

                <Password>
                    <Value>xenha</Value>
                    <PlainText>true</PlainText>
                </Password>

            </AutoLogon>

        </component>

    </settings>

</unattend>
Importante: altere o valor xenha para uma senha segura antes de gerar a imagem. Como o parâmetro PlainText=true está habilitado, a senha ficará visível dentro do arquivo XML.
O que este arquivo faz:
  • Define idioma do sistema como Português (Brasil).
  • Configura teclado pt-BR.
  • Define o fuso horário "E. South America Standard Time".
  • Oculta telas desnecessárias do OOBE.
  • Evita solicitação de conta Microsoft durante a configuração inicial.
  • Cria automaticamente o usuário local Admin.
  • Adiciona o usuário ao grupo Administradores.
  • Realiza um logon automático após a instalação.

4. Limpeza do Sistema Antes do Sysprep

Execute os comandos abaixo em Prompt de Comando como Administrador:

cleanmgr

Dism.exe /Online /Cleanup-Image /StartComponentCleanup /ResetBase

del /s /q %temp%\*

net stop wuauserv
net start wuauserv

rd /s /q C:\Windows\SoftwareDistribution\Download
Recomenda-se reiniciar o computador após a limpeza para garantir que não existam arquivos pendentes.

5. Executar o Sysprep

Copie o arquivo unattend.xml para a pasta do Sysprep caso ainda não esteja lá.

Execute:

C:\Windows\System32\Sysprep\sysprep.exe /generalize /oobe /shutdown /unattend:C:\Windows\System32\Sysprep\unattend.xml

Alternativamente, execute sysprep pela caixa Executar, marque a opção Generalizar e escolha Desligar.

6. Capturar a Imagem do Windows

  1. Inicialize pelo pendrive de instalação do Windows.
  2. Na primeira tela pressione:
SHIFT + F10

Execute:

diskpart
list vol

Verifique se todas as partições possuem letra de unidade. Caso seja necessário: 

select vol 1
assign letter=D
exit

Capture a imagem:

dism /capture-image /imagefile:D:\install.wim /capturedir:C:\ /name:"Win11Custom"
Ajuste as letras das unidades conforme o ambiente utilizado.

7. Inserir o install.wim na Estrutura da ISO

  1. Reinicie o computador.
  2. Entre novamente no modo auditoria usando:
CTRL + SHIFT + F3
  1. Mova o arquivo capturado para: 
    D:\iso\sources\install.wim

8. Instalar o Windows ADK

  1. Baixe e instale o Windows ADK.
  2. Durante a instalação marque apenas: Ferramentas de Implantação.

9. Gerar a ISO Customizada

  1. Execute como Administrador: Ambiente de Ferramentas de Implantação e Geração de Imagens 
oscdimg -u2 -udfver102 -m -o -bootdata:2#p0,e,bD:\iso\boot\etfsboot.com#pEF,e,bD:\iso\efi\microsoft\boot\efisys.bin D:\iso D:\WinCustom.iso

Ajuste as letras de unidade caso necessário.

Ao final do processo será criado o arquivo: D:\WinCustom.iso

Solução de Problemas

Erro do Language Experience Pack durante o Sysprep

Erro:

SYSPRP Package Microsoft.LanguageExperiencePackpt-BR...
was installed for a user, but not provisioned for all users.

Abra o PowerShell como Administrador e execute:

Get-AppxProvisionedPackage -Online |
Where-Object DisplayName -like "*LanguageExperiencePackpt-BR*" |
Remove-AppxProvisionedPackage -Online

Get-AppxPackage -AllUsers -Name "*LanguageExperiencePackpt-BR*" |
Remove-AppxPackage -AllUsers

Após remover o pacote, reinicie o computador e execute o Sysprep novamente.
